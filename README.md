# مكتبة ديالا

موقع (PWA) لقراءة ودراسة كتب PDF، مبني ليتحول لتطبيق آيفون لاحقاً.

## المزايا الحالية
- دخول بحسابين على الخادم (مدير + قارئة)، بدون رموز مخبأة بالكود.
- المدير بيرفع كتب PDF لمكتبة ديالا عن بُعد، وديالا بتقدر ترفع كتبها بنفسها (`/add`).
- قارئ PDF حقيقي (pdf.js): تكبير، انتقال بين الصفحات، سحب، علامات، حفظ آخر صفحة تلقائياً.
- بحث داخل الكتاب وبكل المكتبة (النص بيُستخرج بالمتصفح وقت الرفع).
- مؤقت قراءة وهدف يومي، ثيمات (كريمي، دافئ، ليلي)، رفوف مخصصة، رسالة شخصية قبل الكتاب.
- لوحة إدارة: دقائق القراءة، أيام متتالية، كتب مكتملة، آخر 7 أيام.
- أوفلاين: الكتب بتنحفظ على الجهاز بعد أول فتح.

## البنية
- `src/` الواجهة (React + TypeScript)، `build.mjs` بيبنيها بـ esbuild إلى `dist/`.
- `functions/api/[[path]].ts` و`server/` الـ API على Cloudflare Pages Functions مع D1 (بيانات) وR2 (ملفات).
- `dev/` سيرفر محلي (SQLite وملفات بدل D1 وR2) واختبار شامل بمتصفح حقيقي.

التشغيل والنشر: انظر `DEPLOY.md`.

## الخطوات الجاية
فصول من فهرس الـ PDF، اختبارات، ذكاء اصطناعي (يحتاج خادم وسيط ومفتاح API)، وتغليف Capacitor لـ TestFlight.
